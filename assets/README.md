# assets/ (project root)

Expo's static app-identity assets, referenced by `app.json`: app icon, adaptive icon layers,
splash screen image, and web favicon.

This is **not** for in-app content assets (images/audio/icons used by screens and
components while the game runs) — those live in `src/assets`. This folder is only for the
fixed set of images Expo needs to build the app binary and native app icons.
